## Что сделано

- [base.html](public/base.html) — общий каркас страницы.
- [index.html](public/index.html) — список вопросов.
- [question.html](public/question.html) — вопрос, ответы и форма ответа.
- [ask.html](public/ask.html) — форма добавления вопроса.
- [profile.html](public/profile.html) — настройки профиля и выбор аватара.

- [login.html](public/login.html) — форма входа.
- [signup.html](public/signup.html) — форма регистрации с выбором аватара.

## Как было сделано

Сначала сделал общий каркас в `base.html`: шапку с логотипом, поиском и кнопкой создания вопроса, основную колонку, боковую панель с тегами и участниками, а также футер. Затем скопировал этот каркас в остальные HTML-страницы и добавил их содержимое.

На главной разместил карточки вопросов с аватарками, описанием, тегами, датой и количеством ответов. Показал три состояния голосования: без голоса, с лайком и с дизлайком. На странице вопроса добавил ответы, отметку правильного ответа в двух состояниях, пагинацию и форму ответа.

В форме создания вопроса сделал поля для заголовка, текста и тегов. Добавил подсказки, обязательное заполнение и ограничения длины.

Для оформления Bootstrap не использовал, лишь подключил (не скачивал). Работал с CSS впервые. Приятного просмотра!
